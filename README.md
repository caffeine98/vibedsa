# VibeDSA

Data structures and algorithms in plain English, with tested Python.

**Live site:** https://caffeine98.github.io/vibedsa/

## Run locally
```sh
npm install
npm run dev

python -m venv .venv
.venv/Scripts/pip install -r requirements-dev.txt   # macOS/Linux: .venv/bin/pip
.venv/Scripts/python -m pytest
```

See `STYLE.md` for the writing rules and `CLAUDE.md` for the project layout.
